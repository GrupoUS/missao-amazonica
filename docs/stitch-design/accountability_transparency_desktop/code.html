Reserva Global

A transparência não se limita aos gastos previstos. Quando uma campanha arrecada valores além da meta estipulada, o excedente é direcionado para a nossa Reserva Global.

Este fundo de emergência é estritamente utilizado para:

  • eco Atendimento a emergências climáticas (enchentes ou secas extremas).
  • eco Manutenção não programada de embarcações missionárias.
  • eco Custos logísticos extraordinários devido a mudanças nos rios.
